# Project 1: Medical Insurance Cost Prediction

## Project Description
This project aims to predict individual medical insurance costs based on a number of personal attributes. The analysis is performed using Python and the scikit-learn library.

The script executes the following steps:
1.  Loads and explores the `data_insurance.csv` dataset.
2.  Trains an initial **Linear Regression model** on the raw encoded features.
3.  Evaluates the initial model's performance using R-squared and RMSE.
4.  Performs **feature engineering** by creating interaction terms.
5.  Trains a **refined Linear Regression model** on the new set of features.
6.  Compares the performance of both models and saves the complete output to a text file.

## Requirements
To run this project, you need Python and the following libraries installed:
* pandas
* numpy
* scikit-learn

You can install them using pip:
```bash
pip install pandas numpy scikit-learn
python 23ie10036_p1_sayak.py
```
## Running the Jupyter/Colab Notebook (.ipynb)

1. Choose Your Environment: Open the .ipynb file using Google Colab, Jupyter Notebook, or another notebook editor like VS Code.

2. Place the Dataset:

* In Google Colab: Upload the data_insurance.csv file to the session storage.

* In a local Jupyter Notebook: Make sure the data_insurance.csv file is in the same folder as the notebook.

3. Run the Cells: Execute the code cells sequentially from top to bottom.

## Expected Outcome

When the code is run, it will:

1. Print the analysis steps to the console or notebook output.

2. Create a file named output.txt in the same directory with a detailed summary of both models.

3. If running the .py script on Windows, it will attempt to automatically open the output.txt file.
